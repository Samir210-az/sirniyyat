# Ev Ləzzəti Şirniyyat — CRM

Şirniyyat mağazası üçün sadə, sürətli və tam funksional idarəetmə paneli.

## Xüsusiyyətlər
- 📊 Dashboard — günlük satış, bugünkü sifarişlər, top məhsullar
- 🍰 Məhsullar — kateqoriyalar üzrə, əlavə/redaktə/sil
- 🧾 Sifarişlər — səbət ilə yeni sifariş, status idarəetməsi, endirim
- 👥 Müştərilər — əlaqə, doğum günü, tarixçə, xərclənən məbləğ
- 📈 Hesabatlar — 7 günlük satış qrafiki, kateqoriya bölgüsü, top müştərilər
- 💾 Bütün data brauzerdə (localStorage) saxlanılır, JSON backup mümkündür

## Texnologiya
Vanilla JS + Tailwind CDN + Chart.js — heç bir build addımı yoxdur, birbaşa açıla bilər.

## Deploy
Vercel-ə statik sayt kimi birbaşa import edilir (build command yoxdur).
